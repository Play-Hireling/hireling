# The starter party

Each folder is one hireling: `profile.yaml` (who it is and what it may do — [schema](../docs/reference/profile.md)) and `prompt.md` (how it works).

| Id | Role |
| --- | --- |
| [`innkeeper`](innkeeper/) | Manager: turns orders into tasks, assigns, prioritizes, approves handoffs (planner) |
| [`scriptwriter`](scriptwriter/) | Video scripts, hooks, outlines, blog and newsletter drafts |
| [`social-media`](social-media/) | Posts, carousels, captions, editorial calendar on owned channels |
| [`dev`](dev/) | Branches, PRs, tests, rollbacks of non-critical services |
| [`paid-traffic`](paid-traffic/) | Campaign plans, audiences, ad copy; ad spend capped at 0 until you raise it |
| [`test`](test/) | Smoke test: proves the plumbing end to end |

Add your own: [docs/guides/add-a-hireling.md](../docs/guides/add-a-hireling.md). New templates are welcome as pull requests.
