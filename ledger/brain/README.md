# Tavern Ledger

The shared brain of the tavern (GBrain, E1): markdown pages in git are the source of truth, indexed into Postgres + pgvector. Every hireling reads what its role needs and writes only to its own area; every change is a commit by the hireling that made it (E3). This folder opens as an Obsidian vault (E7).

- [Resolver](RESOLVER.md): where a new page goes — read it before creating one.
- [The quest](goal.md): the shared goal and how each kind of work moves it.
- [Agents](agents/README.md): one page per hireling.
- [Learnings](learnings/README.md): what each hireling learned, one folder each.
- [Projects](projects/README.md): work bigger than one task.
- [Audiences](audiences/README.md): segments, in aggregate.
- [Decisions](decisions/README.md): what the owner and the Innkeeper decided.

Page format and templates: [ledger/templates](../templates/README.md).
