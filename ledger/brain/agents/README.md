# Agents

One page per hireling (the [agent template](../../templates/agent-template.md)). The Innkeeper keeps these; each hireling writes only under its own `learnings/<id>/`.

- [Innkeeper](innkeeper.md): turns what the owner wants into tasks for the party and keeps the bar running; approves handoffs.
- [Scriptwriter](scriptwriter.md): video scripts, hooks, outlines, blog drafts and newsletter copy for the tavern's brand.
- [Social Media](social-media.md): posts, carousels, captions and the editorial calendar for owned channels (Instagram, X, LinkedIn, TikTok).
- [Dev](dev.md): code on branches, pull requests, tests and rollbacks of non-critical services.
- [Paid Traffic](paid-traffic.md): campaign plans, audience research, ad copy and reporting for paid and organic acquisition.
- [Test](test.md): proves the plumbing: takes a command from the Front Desk queue, does it, reports back.
